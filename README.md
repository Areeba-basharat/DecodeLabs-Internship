# DecodeLabs Data Analytics – Project 1

## Data Cleaning & Preparation

### Description

This project focuses on cleaning and preparing a raw dataset for data analysis.

The dataset contains 1,200 orders and 14 columns. The cleaning process included:

- Identifying and handling missing values
- Checking duplicate records
- Checking duplicate Order IDs
- Standardizing date formatting
- Checking text formatting
- Standardizing numeric values
- Verifying the relationship between Quantity, UnitPrice, and TotalPrice

A total of 309 missing CouponCode values were identified and handled by replacing them with `No Coupon`.

After cleaning, the dataset contains 0 missing cells, 0 duplicate Order IDs, and 0 invalid or missing dates.

### How to Run / Use

This is an Excel-based data cleaning project, so no command-line setup is required.

1. Open `DecodeLabs_Project1_Cleaned_Dataset.xlsx`.
2. Use Microsoft Excel or another compatible spreadsheet application to view the workbook.
3. Review the cleaned dataset and data quality report included in the workbook.
4. `DecodeLabs_Project1_Change_Log.pdf` contains the documentation of the cleaning and verification process.
