# Project 4 – Data Visualization

## Project Title
Data Visualization and Business Insights

## Description
This project focuses on presenting data in a simple and understandable visual form. The dataset was cleaned, analyzed, and used to create different charts and summaries to identify useful business insights.

The main purpose of this project is to understand how data visualization can help in identifying patterns, comparisons, and trends in a dataset.

## Dataset Overview
- Total Records: 1,200
- Dataset contains information related to orders, products, payments, order status, referrals, and sales.
- The data was checked and cleaned before visualization.

## Data Cleaning
The following basic cleaning steps were performed:
- Checked for missing values.
- Handled missing CouponCode values as "No Coupon".
- Checked for duplicate records.
- Checked data types and formatting.
- Standardized relevant data fields.
- Verified important numerical values.

## Visualizations Created

### 1. Product Analysis
A bar chart was created to compare revenue generated by different products.

### 2. Payment Method Analysis
A pie chart was used to show the distribution of orders according to payment method.

### 3. Order Status Analysis
Order statuses were grouped and analyzed to understand the distribution of different order outcomes.

### 4. Referral Source Analysis
Referral sources were analyzed to compare the number of orders and revenue generated through different sources.

### 5. Monthly Sales Trend
A line chart was created to show changes in revenue over time and identify monthly trends.

## Key Findings
- Chair generated the highest product revenue.
- Phone generated the lowest product revenue among the analyzed products.
- Online payment had the highest number of orders.
- Cancelled was the most frequent order status.
- Instagram generated the highest revenue among the referral sources.
- June 2024 recorded the highest monthly revenue.
